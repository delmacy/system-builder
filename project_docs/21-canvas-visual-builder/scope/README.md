# Escopo — Canvas / Visual Builder

## Inclui
Visualização/edição de nodes, flows, states, decisions, handoffs, actors, documents e bindings; round-trip com contratos formais.

## Não inclui
Manter estado sem representação persistente independente da UI ou criar DSL própria prematuramente.

## Entradas
BusinessRecipe/SystemDefinition e schemas de autoria.

## Saídas
Alterações formais validáveis nos artefatos, layouts visuais auxiliares.

## Critério de conclusão
O mesmo artefato pode ser lido/escrito sem Canvas e reaberto visualmente sem perda semântica.
