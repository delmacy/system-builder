# Escopo — Runtime Compatibility Certification

## Inclui
Builder-off tests, environment compatibility, export/restore, upgrade/downgrade/rollback, capability/runtime version matrix e certification evidence.

## Não inclui
Declarar compatibilidade baseada só em documentação.

## Entradas
Release, Runtime version, Environment Profile e supported matrix.

## Saídas
CertificationReport e pass/fail evidence por capability/propriedade.

## Critério de conclusão
Afirmações de autonomia/compatibilidade possuem testes reproduzíveis executados contra release real.
