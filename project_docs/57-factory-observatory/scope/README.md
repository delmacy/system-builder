# Escopo — Platform Self-Observation / Factory Observatory

## Inclui
Task duration, model/provider cost, retries, PR/review outcomes, test failures, rework, architecture violations, pipeline stage latency e agent quality metrics.

## Não inclui
Usar produtividade individual como vigilância punitiva nem otimizar apenas velocidade.

## Entradas
Agent harness ledger/receipts, Git/CI data, cost data e factory artifacts.

## Saídas
Factory telemetry, bottleneck/quality findings e model-routing evidence.

## Critério de conclusão
É possível medir onde a fábrica perde tempo/dinheiro/qualidade e distinguir problema de modelo, spec, tooling ou arquitetura.
