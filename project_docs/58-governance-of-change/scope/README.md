# Escopo — Governance of Change

## Inclui
Change levels, approval authorities, ADR triggers, impact analysis, migration/rollback requirements, deprecation windows e emergency change path.

## Não inclui
Criar burocracia igual para mudança trivial e mudança constitucional.

## Entradas
Change proposal, impact graph, risk/compatibility/security evidence e affected owners.

## Saídas
Approved/rejected/deferred ChangeRecord, required gates e rationale.

## Critério de conclusão
Toda mudança L3/L4 possui authority, impacto e decisão explícitos; L4 exige ADR conforme constituição atual.
