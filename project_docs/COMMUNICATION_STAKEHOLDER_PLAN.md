# Communication & Stakeholder Plan

## Stakeholders iniciais
- Product/architecture owner
- Human operators/developers
- AI agents
- Future client/process owners
- Runtime operators/support

## Artefatos como comunicação
Main branch = verdade integrada; ADR = decisão arquitetural; WBS/WP = escopo; task pack = instrução de execução; PR = unidade de review; release evidence = prova.

## Cadência
- per task: evidence + PR review
- per sprint: sprint review/retro curta
- periodic system review: integration/debt/architecture
- per milestone: scope/risk/quality/benefit review

Decisões não devem permanecer apenas em chat; decisões duráveis são promovidas para o repositório.
