# Escopo — Experiment & Improvement

## Inclui
Hypothesis, baseline, intervention, metrics, observation window, comparison, decision e promotion/revert links.

## Não inclui
Inferir causalidade automaticamente sem desenho/evidência suficiente.

## Entradas
Findings, dados históricos, proposta de mudança e indicadores.

## Saídas
ExperimentRecord e decisão evidence-backed sobre evolução.

## Critério de conclusão
Uma mudança importante pode ser ligada à hipótese original, dados prévios, intervenção e resultado medido.
