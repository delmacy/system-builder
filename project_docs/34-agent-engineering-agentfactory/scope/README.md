# Escopo — Agent Engineering / AgentFactory

## Inclui
Task contracts/packs, model routing, bounded context, executor adapters, orchestration, Git workflow, verification receipts, review/merge gates e cost/quality metrics.

## Não inclui
Transformar o harness em segundo produto ou permitir agente alterar arquitetura fora do task scope.

## Entradas
Specs/tasks, repository state e model/executor configuration.

## Saídas
Branches/PRs/evidence/state updates executados sob política.

## Critério de conclusão
Trocar IA executora não muda a definição do trabalho nem a autoridade dos gates.
