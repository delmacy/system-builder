# Escopo — Autonomous Runtime

## Inclui
Auth, APIs, UI, workflows, actions, database, jobs, events, files, integrations e configuração runtime necessária.

## Não inclui
Mirror, Recipe authoring, Analysis, Canvas, Compiler ou Release management.

## Entradas
Release implantada e Environment configuration.

## Saídas
Sistema cliente operante, seus dados/eventos e interfaces de integração/telemetria opcionais.

## Critério de conclusão
Desligar o Builder não interrompe login, APIs, DB, workflows, jobs ou integrações do cliente.
