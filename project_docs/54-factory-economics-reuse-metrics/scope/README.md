# Escopo — Factory Economics / Reuse Metrics

## Inclui
Reuse ratio, custom ratio, lead time, engineering cost, defects, maintenance effort, capability reuse, second-system effect e lifecycle cost.

## Não inclui
Usar LOC ou número bruto de componentes como métrica isolada de sucesso.

## Entradas
Factory artifacts, task/evidence data, costs, defects/support records e releases.

## Saídas
FactoryEconomics metrics/cohorts e improvement findings.

## Critério de conclusão
É possível demonstrar se sistemas posteriores ficaram mais baratos/rápidos/seguros por reutilização real.
