# Escopo — Migration & Legacy Transition Engine

## Inclui
Legacy discovery, mapping, coexistence, sync, migration waves, reconciliation, cutover, rollback, retirement e evidence.

## Não inclui
Bulk-copy automático do legado nem big-bang como padrão.

## Entradas
Legacy inventory/data/processes, target definitions e integration mappings.

## Saídas
MigrationPlan, reconciliation evidence, cutover/rollback records e retirement status.

## Critério de conclusão
Cada wave conhece source/target ownership, migration rules, validation, rollback e exit criteria.
