# Escopo — Disaster Recovery / Continuity Plane

## Inclui
RTO/RPO, backup/restore, recovery plans, degraded modes, dependency failure, drills, failover/rollback e continuity evidence.

## Não inclui
Considerar backup não testado como DR completo.

## Entradas
Criticality, architecture/dependencies, data stores e environment profiles.

## Saídas
Recovery/continuity plans, test evidence e readiness findings.

## Critério de conclusão
Serviços críticos possuem recovery objective e restauração comprovada periodicamente.
