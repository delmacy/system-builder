# Quality Management Plan

## Dimensões
- Contract/schema correctness
- Architecture conformance
- Determinism/reproducibility
- Functional correctness
- Security/privacy
- Runtime autonomy/portability
- Operability/observability
- Documentation/traceability

## Quality gates
1. Contract gate
2. Unit/component gate
3. Integration gate
4. Architecture fitness gate
5. Vertical end-to-end gate
6. Release/autonomy gate

## Defect policy
Defeito bloqueante não é convertido silenciosamente em dívida técnica. Dívida aceita exige registro, owner lógico, impacto, condição de pagamento e review date.

## Evidence
Test output, fixtures, hashes, contract compatibility, integration proof, build/release provenance e documentação atualizada.
