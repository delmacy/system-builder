# Escopo — Knowledge Boundary

## Inclui
Classificação generic/client-proprietary/personal/trade-secret, policies de uso, isolamento, promotion gate e controles para AI/catalog.

## Não inclui
Usar margens, fornecedores, clientes ou estratégia proprietária para negócios do grupo sem autorização/base legítima.

## Entradas
Dados, evidências, patterns e candidatos a reutilização.

## Saídas
Classification/policy decisions e conhecimento genérico aprovado para catálogo.

## Critério de conclusão
É possível demonstrar por que um asset reutilizado é genérico e que informação sensível não foi carregada.
