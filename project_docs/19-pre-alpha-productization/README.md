# 19 — Pre-Alpha Productization

This milestone is a forecast baseline for the integration/productization work required after M18 closes. It does not supersede the active M18 package, does not authorize execution and must be re-derived from fresh `main` before any P19 Work Package is promoted.

The milestone exists because the repository already contains bounded implementations and tests for Assembly, Validation, Compiler, Release, Deploy, autonomous Runtime, Observe and Support/Evolution, while no post-M18 WBS currently defines the product-level proof that composes those capabilities into one operator-runnable factory journey and a formal pre-alpha release gate.

The pre-alpha objective is intentionally narrow: prove that one real approved process can traverse the supported factory path into a deployable autonomous runtime, that the path is repeatable on a clean environment, that evolution preserves lineage, and that known limitations are explicit.

See `WBS.md` for the forecast package decomposition and `scope/README.md` for boundaries and acceptance intent.
