# Scope — M19 Pre-Alpha Productization

## In scope
- one canonical vertical factory journey using real public contracts;
- deterministic composition from approved/versioned business input to deployment;
- clean-environment bootstrap and maintainer/operator diagnostics;
- generated autonomous runtime handoff in the existing initial deployment target;
- Builder-off operation and bounded upgrade/rollback proof;
- one real maintainer-owned dogfood system/process;
- reproducible pre-alpha acceptance evidence and explicit known limitations.

## Out of scope by default
- architectural redesign of closed milestones;
- production UX completeness or full low-code canvas;
- SaaS/multi-tenancy, billing, marketplace or commercial onboarding;
- new deployment topologies;
- unrelated conformance/productization findings or carried debt unless demonstrated as hard blockers;
- second-system full factory proof, beta/public readiness and production SLA.

## Acceptance intent
Pre-alpha means the factory is usable by its maintainers as a real product path rather than only as isolated module APIs/tests. It may remain incomplete and non-production-ready, but its critical path must be real, traceable, repeatable, diagnosable and autonomous after publication.
