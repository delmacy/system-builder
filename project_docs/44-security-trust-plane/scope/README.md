# Escopo — Security Architecture / Trust Plane

## Inclui
Threat modeling, trust boundaries, secrets, cryptographic identity/signing, SBOM/provenance, vulnerability management, tenant isolation, secure defaults e incident hooks.

## Não inclui
Tratar compliance checklist como prova suficiente de segurança.

## Entradas
Architecture, components/dependencies, deployment profiles e threat context.

## Saídas
Threat models, security requirements/gates, trust artifacts e findings.

## Critério de conclusão
A superfície crítica possui ownership, threat assumptions, controls e verificação automatizável quando possível.
