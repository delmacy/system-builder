# Cost & Finance Planning

## Tailored baseline
Nesta fase não há orçamento contratual rígido; portanto custo será tratado como guardrail mensurável, não falsa precisão.

## Cost buckets
- AI/API tokens
- CI minutes/compute
- preview/prod hosting
- database/storage
- observability
- paid dependencies/services
- human review time

## Before scheduling
Cada milestone futuro deve possuir estimate range e principais cost drivers. Work Packages de alto custo variável devem ter budget/usage guardrails.

## Later
Quando houver operação comercial, promover para cost baseline e performance measurement integrados a Factory Economics.
