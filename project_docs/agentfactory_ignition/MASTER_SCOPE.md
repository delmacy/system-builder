# Master Scope

## In scope
- DAG/READY deterministic engine;
- Work Package/task decomposition support;
- sprint forecast/commitment support;
- model routing;
- OpenCode adapter;
- execution harness;
- validation/evidence;
- GitHub branch/PR/merge integration;
- state ledger;
- replanning/review;
- metrics/cost;
- minimal operator controls.

## Out of scope
- general-purpose agent platform;
- marketplace/UI product;
- generic workflow SaaS;
- replacing GitHub;
- full autonomous architecture decision authority;
- infrastructure unrelated to System Builder delivery.

## Success
A READY task can traverse Task Pack -> OpenCode -> verify -> PR -> evidence -> DONE -> successor READY with bounded human intervention.
