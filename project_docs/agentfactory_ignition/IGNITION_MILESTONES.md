# Ignition Milestones

- **I0 Governance Ready** — políticas e gates definidos.
- **I1 Single Task Autonomous** — uma task completa ponta a ponta.
- **I2 Sequential Pipeline** — várias tasks dependentes executadas em sequência automática.
- **I3 Sprint Autonomous** — sprint candidata gerada, executada e fechada com evidência.
- **I4 DAG Autonomous** — READY queue e desbloqueios automáticos.
- **I5 Review/Replanning** — rework, debt e forecast atualizados automaticamente.
- **I6 Parallel Execution** — ramos independentes com WIP/capacidade controlados.
- **I7 Self-Operating Factory** — intervenção humana concentrada nos governance gates.

## Exit strategy
I2/I3 já justificam retomar o foco majoritário no System Builder. I4+ evoluem conforme gargalos reais.
