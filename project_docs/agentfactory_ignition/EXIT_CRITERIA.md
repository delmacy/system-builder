# Exit Criteria

AgentFactory remains infrastructure, not a destination.

## I1 exit
One existing READY task executes through OpenCode, bounded paths, verify, evidence and PR without manual context reconstruction.

## I2 exit
At least two dependent tasks execute sequentially with successor readiness derived from evidence.

## I3 exit
One unnumbered sprint candidate is committed, all committed tasks close, sprint evidence is recorded and forecast refresh occurs.

## Stop adding infrastructure when
New work does not directly improve planning, execution, validation, integration, safety or measurable learning for System Builder delivery.
