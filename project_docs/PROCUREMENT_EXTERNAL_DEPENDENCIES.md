# Procurement & External Dependencies Plan

## Scope
APIs/model providers, hosting, database/storage services, external libraries, SaaS integrations e serviços necessários à fábrica/runtime.

## For each critical dependency
Owner/vendor; purpose; license/terms; version strategy; portability; failure mode; substitute; data exposure; cost model; SLA where applicable.

## Principle
Nenhum provider externo deve se tornar lock-in oculto. Dependência crítica sem substitute/exit strategy exige risco explícito.
