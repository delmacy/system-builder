## Techniques rotated beyond Full Passes 1–3

This revisit deliberately changed the composition lens rather than repeating prior dialect/version-skew checks:

1. **Profile-intersection lattice mutation** — vary base standard, declared profile, extension vocabulary, optional feature subset and intermediary behavior so each adjacent pair remains valid while the end-to-end intersection loses one required semantic dimension.
2. **Intermediary canonicalization non-commutativity** — reorder media-type negotiation, transcoding, normalization, default injection, extension stripping and signature/hash verification to test whether equivalent-looking local transforms produce inequivalent end-to-end claims.
3. **Critical-field survival braid** — keep producer and consumer individually conformant while an intermediary legally drops, renames or defaults a field whose domain owner treats absence, null, default and delete as distinct operators.
4. **Directional compatibility inversion** — preserve a supported A→B/read relation and deliberately reuse it as B→A/write, replay, rollback or old-client/new-server evidence to test unsafe scalar compatibility promotion.
5. **Effect-identity splice** — vary operation revision, idempotency-key scope, external identifier, target revision and provider route while holding HTTP/transport success semantics constant, then test whether acknowledgement is mispromoted to canonical effect certainty.
6. **Residual-cohort negotiation race** — negotiate a stronger profile for new traffic while old clients/adapters/providers remain able to emit syntactically valid but semantically weaker authoritative writes.
7. **Trust/privacy/authority subtraction** — remove one non-wire requirement at a time from otherwise valid profile negotiation to test whether compatibility machinery silently widens authority, trust namespace or information release.
8. **Pathological contract-product pressure** — compose recursive schemas, content alternatives, extension sets, profile variants and generated adapters to challenge bounded analysis and safe `INCONCLUSIVE` behavior under combinatorial growth.
9. **Human-instruction semantic fork** — provide two locally correct integration runbooks that choose different profile/default/canonicalization behaviors and test whether procedure conformance can still produce contradictory canonical effects.
10. **AI/low-code semantic-preservation differential** — synthesize syntactically valid adapters/contracts that retain shape and transport success while deleting semantic owner, presence operator, compatibility direction, currentness, authority or effect evidence.
