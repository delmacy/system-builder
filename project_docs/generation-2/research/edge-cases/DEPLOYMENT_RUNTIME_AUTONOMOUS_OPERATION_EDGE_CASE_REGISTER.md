## Evidence anchors

- Kubernetes Deployment status explicitly exposes the controller's `observedGeneration` separately from desired generation and reports ready/available replicas as observations; this supports the portable distinction `desired state != controller-observed state != runtime-effective business state`. Source: Kubernetes Deployment API reference, accessed 2026-09-04: https://kubernetes.io/docs/reference/kubernetes-api/apps/deployment-v1/
- Kubernetes rollback restores the Deployment Pod template revision; other state is not implied to roll back with it. This is concrete evidence that retained deployment history is narrower than whole-system rollback eligibility. Source: Kubernetes Deployments, accessed 2026-09-04: https://kubernetes.io/docs/concepts/workloads/controllers/deployment/
- Kubernetes documents a StatefulSet forced-rollback failure mode where reverting the template alone is insufficient and manual removal of already-created bad Pods is required. This supports residual-cohort/recovery qualification rather than `rollback requested == converged`. Source: Kubernetes StatefulSets documentation, accessed 2026-09-04.
- Amazon ECS deployment circuit breaker distinguishes deployment failure, steady-state completion and rollback to the most recent `COMPLETED` deployment; rollback eligibility depends on an eligible completed deployment and can stall if none exists. Source: Amazon ECS deployment circuit breaker documentation, accessed 2026-09-04: https://docs.aws.amazon.com/AmazonECS/latest/developerguide/deployment-circuit-breaker.html
- Amazon ECS alarm-based failure detection may leave deployment status `IN_PROGRESS` through bake time even after task-set changes, reinforcing that control-plane lifecycle state and observed service behavior have different clocks/currentness. Source: Amazon ECS deployment alarm failure documentation, accessed 2026-09-04.

These representatives support portable semantics only; their mechanisms are not promoted as universal architecture.

Proof: `RUNTIME-ADV-PROOF-001`.
