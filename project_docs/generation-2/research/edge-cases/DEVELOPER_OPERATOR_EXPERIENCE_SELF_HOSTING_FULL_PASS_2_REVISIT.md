## Techniques materially different from Full Pass 1

This revisit emphasized composed-procedure analysis rather than rediscovering the original seven scenarios:

1. **Instruction-set braid analysis** — compose docs, CLI help, generated runbooks, operator memory and provider instructions that are each locally valid but may target different revisions or preconditions.
2. **Truth-surface differential** — compare operator-visible green/success surfaces with owner-qualified runtime, business, security and recovery postconditions.
3. **Evidence-hole mutation** — remove, redact, delay or age one diagnostic cohort at a time and test whether conclusions silently widen beyond evidence coverage.
4. **Authority path inversion** — start from local/root/provider credentials and attempt to infer upward Enterprise/Station/Role/Person authority that was never granted.
5. **Maintenance interleaving matrix** — interleave upgrade, restore, provider substitution, config/trust rotation, retry and authority change around ambiguous administrative effects.
6. **Disconnected-closure subtraction** — remove one dependency, revocation source, trust update, artifact, entitlement/policy input or external support assumption from an air-gapped profile and test whether the profile still claims indefinite qualification.
7. **Residual-cohort resurrection** — allow old agents/config/providers to survive cutover or restore and test whether they regain authoritative effect silently.
8. **AI/low-code instruction mutation** — reorder or optimize individually safe steps, suppress evidence collection, broaden support bundles or repeat repair actions, then test authority/resource/privacy invariants.
