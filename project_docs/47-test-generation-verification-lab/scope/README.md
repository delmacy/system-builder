# Escopo — Test Generation & Verification Laboratory

## Inclui
Contract tests, invariants, scenario generation, fixtures, property/model-based tests, traceability coverage e regression suites.

## Não inclui
Assumir que teste gerado por IA é correto sem oracle/constraint confiável.

## Entradas
Recipe, SystemDefinition, contracts, rules/capabilities e known incidents.

## Saídas
Test specifications/cases/fixtures, coverage evidence e verification findings.

## Critério de conclusão
Requisitos críticos possuem evidência de verificação e links rastreáveis, inclusive casos negativos/boundaries.
