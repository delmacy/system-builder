# Escopo — Portability / Anti-lock-in

## Inclui
Export/import de dados e arquivos, contracts/schemas documentados, autonomous runtime, environment schemas, replaceable providers/modules e exit documentation.

## Não inclui
Prometer portabilidade sem teste nem obrigar tecnologia única para self-hosting.

## Entradas
Release/runtime state, schemas/contracts e storage/data sources.

## Saídas
Portable export packages, compatibility docs e autonomy/exit evidence.

## Critério de conclusão
Um cliente pode operar/transferir o sistema e seus dados sem depender de chamada proprietária ao Builder.
