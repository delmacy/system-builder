# Escopo — Multi-organization / Federation Model

## Inclui
Organization boundaries, federation relationships, cross-org actors/processes, delegated authority, shared resources/contracts e data/access isolation.

## Não inclui
Presumir confiança entre organizações ou compartilhar dados automaticamente por pertencerem ao mesmo grupo.

## Entradas
Organization graph, contracts/relationships, identities e process definitions.

## Saídas
Federation model, cross-org access/authority context e exchange boundaries.

## Critério de conclusão
Um processo entre empresas distintas pode ser modelado com ownership, authority e data boundaries explícitos.
