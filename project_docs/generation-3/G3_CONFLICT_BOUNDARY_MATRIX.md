## Deduplication rule

When two fronts consume the same fact, the semantic owner remains singular. Other families receive qualified references, observations, analyses or projections. No front creates a parallel canonical representation merely for convenience.

## Graph deduplication

`Canonical Relations -> Query Projection -> Search Index -> Canvas Graph -> Digital Thread -> Complexity/Analysis Graph` describes derivation/projection roles; it does not authorize six competing truth stores.
