# Escopo — Cost & Resource Accounting

## Inclui
Compute/storage/network/API/AI/support/resource usage, allocation keys, cost centers/tags, unit cost e budget/variance telemetry.

## Não inclui
Criar lançamento contábil oficial ou maquiar transferência intragrupo como criação de valor consolidado.

## Entradas
Usage telemetry, provider bills/rates, allocation policies e process/capability context.

## Saídas
CostAllocationRecords, unit-cost views e variance findings.

## Critério de conclusão
Custos relevantes podem ser explicados até seus drivers e premissas de rateio.
