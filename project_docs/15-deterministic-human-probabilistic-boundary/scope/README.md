# Escopo — Deterministic/Human/Probabilistic Boundary

## Inclui
Classificação de behavior/decision points, regras de escalonamento/approval, confidence e políticas para uso de inferência em caminhos críticos.

## Não inclui
Impor IA onde decisão humana/regra determinística basta.

## Entradas
Recipes, SystemDefinitions e capabilities decisórias.

## Saídas
Metadata/policies que tornam a natureza da decisão auditável e verificável.

## Critério de conclusão
Nenhuma saída probabilística governa silenciosamente uma garantia determinística ou decisão humana reservada.
