# WBS — 39 Simulation / What-if

## 39.0 Simulation / What-if
### 39.1 Scenario model
- **39.1.1** Definir baseline, variables, constraints e intervention parameters.
- **39.1.2** Definir horizon, demand/capacity assumptions e distributions.
- **39.1.3** Versionar scenario/model/seed quando aplicável.
### 39.2 Simulation execution
- **39.2.1** Executar deterministic/discrete/stochastic adapters conforme caso.
- **39.2.2** Calcular throughput, queue, utilization, cost/SLAs relevantes.
- **39.2.3** Repetir runs/sensitivity para quantificar incerteza.
### 39.3 Comparison e decision support
- **39.3.1** Comparar scenarios com baseline e guardrails.
- **39.3.2** Expor assumptions/limitations, não só score final.
- **39.3.3** Encaminhar recomendação como input humano, nunca auto-apply.
