# Escopo — Simulation / What-if Engine

## Inclui
Scenario definitions, parameter changes, process/capacity models, stochastic/deterministic simulation adapters, comparative outcomes e sensitivity.

## Não inclui
Prometer previsão exata ou aplicar cenário automaticamente à produção.

## Entradas
Process models, economic/capacity parameters, distributions/baselines e scenario assumptions.

## Saídas
ScenarioResults com assumptions, confidence/uncertainty e comparisons.

## Critério de conclusão
Resultado pode ser reproduzido a partir de modelo, parâmetros, seed/version e premissas registradas.
