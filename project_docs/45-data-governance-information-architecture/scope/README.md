# Escopo — Data Governance & Information Architecture

## Inclui
Data ownership/stewardship, classification, canonical IDs, master/reference data, quality rules, lineage, retention, source-of-truth e synchronization policy.

## Não inclui
Centralizar todos os dados num único banco nem confundir schema técnico com significado do dado.

## Entradas
Business concepts, schemas, integrations, policies e runtime data flows.

## Saídas
Data domains/contracts/policies, quality findings e lineage/ownership metadata.

## Critério de conclusão
Dado crítico possui significado, owner, source-of-truth, quality expectations e lifecycle explícitos.
