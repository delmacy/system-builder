# Roadmap Stage Exit Criteria

This roadmap architecture stage is accepted when: dependency semantics are explicit; whole-system coarse DAG has no intentional cycles; milestone exit gates exist; false sprint-number dependencies are prohibited; rolling forecast/commitment rules exist; review/replanning rules exist; machine schema/validation rules exist; and the next detailed horizon/gate is defined.

Actual sprint creation remains gated on detailed WP/task data and estimates.
