# Integration & Technical Debt Review Template

Goal: assess system health across recently integrated increments rather than add unrelated feature scope.

Inspect: end-to-end integration; contract/schema drift; architecture fitness; duplicated abstractions; regressions/test gaps; security/trust; CI reliability; documentation; performance where relevant; technical debt; dependency accuracy; actual-vs-estimated effort.

Outputs: findings with severity, corrective WPs/tasks, updated risks, updated DAG/readiness, updated forecast/estimates, explicit go/no-go for next construction cycle.

Urgent defects may be corrected during the review when bounded. Larger corrections become traceable corrective work before affected successors proceed.
