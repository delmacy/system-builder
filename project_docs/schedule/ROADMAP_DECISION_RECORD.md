# Roadmap Decision Record

Decision: maintain a complete coarse capability/WP dependency architecture, but progressively elaborate task-level schedule and sprint packages.

Rationale: preserves scope completeness and dependency correctness while allowing real execution evidence to improve later task decomposition and estimates.

Consequence: the project can forecast several sprints, but only near-horizon READY work becomes committed. Completed sprints close normally; later discoveries generate traceable work instead of keeping old sprint scope open.
