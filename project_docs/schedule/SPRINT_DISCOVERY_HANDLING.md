# Discovery During Execution

Classify discoveries as: current-goal defect, future approved-scope work, decomposition correction, or scope change.

Current-goal defect: resolve within sprint when bounded.
Future approved-scope work: add to correct WP/backlog and reevaluate readiness.
Decomposition correction: refine future WP/task/DAG artifacts with traceability.
Scope change: use change governance before scheduling.

This classification replaces the idea of leaving a sprint indefinitely open for unknown dependent work.
