# Schedule Change Handling

Schedule variance does not automatically mean scope change. Reordering READY work, changing estimates, moving forecast contents or using safe parallelism updates schedule and forecast artifacts.

Use scope/change governance when a variance reveals a new deliverable, removes an approved deliverable, changes an authoritative contract or requirement, or materially changes acceptance boundaries.

Changing an active sprint remains exceptional and must preserve its Goal or be recorded as an explicit planning decision.
