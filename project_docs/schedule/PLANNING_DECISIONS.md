# Planning Decisions

- Build the whole-project dependency architecture now.
- Do not freeze the whole-project sprint calendar now.
- Use rolling-wave planning for tasks/sprints.
- Close each sprint when its Goal/DoD is met; do not keep it open for unknown successor work.
- Feed discoveries into explicit successor/corrective backlog items.
- Treat sprint numbering as presentation/execution order, never as dependency semantics.
- Default to sequential execution initially, while preserving safe parallel lanes.
- Use evidence-based milestones and periodic system integration/debt review.
