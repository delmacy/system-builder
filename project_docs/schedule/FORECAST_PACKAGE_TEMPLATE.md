# Forecast Package Template

```yaml
forecast:
  baseline_version: ...
  target_milestone: ...
  generated_from_dag: ...
  candidate_sprints:
    - goal: ...
      ready_tasks: []
      conditionally_ready_tasks: []
      blocking_gates: []
  review_cycle_due: false
  assumptions: []
```

Forecast packages are regenerated from current evidence and are not execution commitments.
