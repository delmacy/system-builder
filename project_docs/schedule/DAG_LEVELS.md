# DAG Levels

Use three linked DAG resolutions:

1. Capability DAG — whole-project architecture and major module dependencies.
2. Work Package DAG — planning/control dependencies and milestone gates.
3. Task DAG — near-horizon executable dependencies used for sprint loading and critical-path calculation.

Do not model the entire project at task-level years in advance. Refine the task DAG by rolling wave while preserving traceability to the stable WP/capability DAG.
