# Work Package to Sprint Transformation

A Work Package is not automatically one sprint. It may be smaller than a sprint, span several sprints, or share a sprint with other READY work when one coherent Sprint Goal exists.

Transformation: WP -> activities/tasks -> task DAG -> estimates -> increment grouping -> READY queue -> sprint candidate.

Never split solely to fit arbitrary sprint numbering; split on independently verifiable outputs, dependencies and integration boundaries.
