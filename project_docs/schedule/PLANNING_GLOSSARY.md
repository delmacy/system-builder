# Planning Glossary

- Scope Baseline: approved definition of project deliverables/boundaries.
- Work Package: lowest controlled WBS outcome used for planning/control.
- Activity/Task: executable work derived from a WP.
- Dependency gate: verifiable condition that unlocks a successor.
- DAG: directed acyclic dependency network.
- Milestone: evidence-based significant state.
- Increment: integrated demonstrable capability, possibly spanning sprints.
- Forecast sprint: probable future loading, changeable.
- Committed sprint: active controlled execution window.
- READY queue: executable tasks with satisfied gates.
- Critical path: duration-driving chain in the estimated task network.
- Float: scheduling flexibility without moving target completion.
