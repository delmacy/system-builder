# Dependency-driven Roadmap

The roadmap is generated from the dependency network, not from arbitrary sprint numbering.

Long horizon: capabilities, WPs, milestone graph and coarse DAG are maintained across the project.
Near horizon: WPs are decomposed into tasks, estimates and machine-readable gates; critical path and READY queue are calculated; a small sprint forecast package is generated.
Execution: one sprint is committed, closed on Goal/DoD, evidence updates the DAG, and forecast is refreshed.
Review: periodic integration/debt cycles inspect the system and can generate corrective work or replan the forecast.

This supports sequential execution initially and safe parallel execution later.
