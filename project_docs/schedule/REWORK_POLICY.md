# Rework Policy

When later integration exposes a defect in completed work, create a corrective item linked to the original WP/task, defect evidence and affected successors.

Do not reopen historical sprint scope merely to make the history look continuous. Rework must be measurable: cause, affected contract, effort, model/agent if relevant, regression test and prevention action.

Repeated rework patterns feed architecture fitness, task templates and agent-selection policy.
