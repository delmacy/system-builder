# Planning Handoff to Sprint Generation

The roadmap layer is complete enough to hand off when the first planning horizon has detailed WPs, task decomposition, dependency gates and estimates.

The sprint generator then receives constraints, not an open-ended architecture problem: READY queue, target milestone, capacity, review cadence, contract versions, acceptance/evidence and critical-path information.

Its output is a sprint candidate for approval/commitment. Execution evidence returns to the planner to update readiness and forecast.
