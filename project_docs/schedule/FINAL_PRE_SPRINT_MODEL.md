# Final Pre-sprint Model

```text
Scope/WBS
  -> Work Packages
  -> WP dependency DAG
  -> Milestones/Increments
  -> near-horizon task decomposition
  -> task DAG + estimates
  -> critical path + READY queue
  -> forecast sprint package
  -> commit one sprint
  -> execute/validate/integrate
  -> evidence/actuals
  -> refresh DAG/forecast
  -> periodic integration review
  -> repeat
```

This is the operating bridge between project planning and the future autonomous AgentFactory execution pipeline.
