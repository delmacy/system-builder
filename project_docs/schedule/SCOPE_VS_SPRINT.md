# Scope Baseline vs Sprint Adaptation

Project scope answers what deliverables belong to the System Builder. Work Packages answer what controlled outcomes produce those deliverables. The DAG answers what must precede what. Sprint planning answers which currently READY tasks will be attempted next.

Learning after a sprint can refine future task decomposition and estimates without reopening completed sprint scope. If learning changes the approved deliverable itself, use change governance and update the Scope Baseline.
