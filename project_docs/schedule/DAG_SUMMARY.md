# DAG Summary

The System Builder planning model now separates:

- what exists: Scope/WBS;
- what controlled outcome is needed: Work Package;
- what must precede what: DAG/gates;
- what integrated state matters: milestone/increment;
- what can execute now: READY queue;
- when it executes: sprint;
- what execution proved: evidence/actuals.

This separation allows sequential execution today and safe parallelism later without changing dependency semantics.
