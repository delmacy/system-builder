# Dependency-driven Schedule Planning

This folder is the bridge from controlled scope to future sprint execution.

- `DAG.md`: dependency network and release rules.
- `LOGICAL_WAVES.md`: dependency maturity waves and parallel lanes.
- `SPRINT_GENERATION_POLICY.md`: rolling-wave policy and sprint scope rules.
- `SCHEDULE_SUPPORT.md`: milestones, critical path, loading gates and traceability.

No numbered sprint backlog belongs here yet. Sprints will be generated only after Work Packages are decomposed into activities/tasks and estimates make a schedule baseline defensible.

Core principle: **the DAG determines what may execute; the sprint determines when a ready item is executed.**
