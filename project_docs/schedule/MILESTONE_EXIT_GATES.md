# Milestone Exit Gates

M0: planning artifacts accepted and authoritative sources reconciled.
M1: semantic/identity primitives have stable contracts and tests.
M2: process knowledge can be captured with version/provenance evidence.
M3: one representative process traverses Recipe -> Analysis -> Design deterministically.
M4: capabilities can be identified/versioned/resolved through catalog contracts.
M5: one thin system slice assembles and validates end to end.
M6: that slice compiles/runs autonomously under defined runtime contract.
M7: release, deploy and rollback are reproducible/traceable.
M8: deployed runtime produces usable observation/support evidence.
M9: observed evidence can drive a controlled improvement cycle back into planning/design.
