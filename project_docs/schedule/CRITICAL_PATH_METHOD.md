# Critical Path Derivation

The current DAG defines precedence but not defensible duration. Critical path is calculated only after READY/NOW Work Packages are decomposed into estimable activities.

For each activity record optimistic/most-likely/pessimistic or agreed deterministic estimate, required resource/agent class, predecessor gates and integration/review overhead.

Then calculate earliest start/finish, latest start/finish and total float. Zero/near-zero-float paths receive explicit risk attention.

Do not optimize the plan by forcing every item onto the critical path. Independent capabilities should retain float and parallel opportunity.

Recalculate when actual duration materially differs, a dependency changes, a risk occurs, a contract gate moves or approved scope changes.
