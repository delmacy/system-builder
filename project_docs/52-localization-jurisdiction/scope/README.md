# Escopo — Localization & Jurisdiction Layer

## Inclui
Locale/language, date/number/currency formats, timezone/calendar, translation resources, jurisdiction profiles e policy/compliance bindings.

## Não inclui
Codificar legislação internacional no core sem fonte/versionamento especializado.

## Entradas
Locale/jurisdiction context, translations, calendars e applicable policy packs.

## Saídas
Resolved localization/jurisdiction configuration e compatibility findings.

## Critério de conclusão
Mesma capability pode operar em localidades distintas com diferenças explícitas e versionadas.
