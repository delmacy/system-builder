# Escopo — Validation

## Inclui
Contract validation, architecture validation, software quality/security gates e business traceability.

## Não inclui
Corrigir automaticamente falhas ou dispensar revisão humana onde exigida.

## Entradas
Recipe, Analysis, Definition, AssemblyPlan, testes e evidências.

## Saídas
ValidationEvidence com gates aprovados/reprovados e trace links.

## Critério de conclusão
É possível provar requisito → design → capability → teste/evidência → release gate.
