# Escopo — Process Versioning

## Inclui
Identidade/version de Mirror/Recipe, revisions imutáveis, diffs semânticos, migration/evolution metadata e links para SystemDefinition/Release.

## Não inclui
Usar Git commit como único modelo de versão de negócio.

## Entradas
Artefatos de conhecimento e mudanças aprovadas.

## Saídas
Histórico versionado, diff, supersession/deprecation e traceability.

## Critério de conclusão
Pode-se reconstruir o que mudou no processo, por quê e qual software materializou cada versão.
