# Escopo — System Analysis

## Inclui
Requisitos, capability matching, gaps, adaptações, integrações, segurança, sizing, infraestrutura e economia/processo quando houver dados.

## Não inclui
Gerar código, resolver dependências concretas ou publicar release.

## Entradas
BusinessRecipe, Business Catalog, Software Catalog, constraints e perfis de carga.

## Saídas
SystemAnalysis com requisitos, matches, gaps e decisões/recomendações rastreáveis.

## Critério de conclusão
Cada necessidade relevante da Recipe está classificada como atendida, adaptada, customizada, integrada ou ainda não resolvida.
