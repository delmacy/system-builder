# Escopo — Document / Evidence Engine

## Inclui
Document types, metadata, versions, validity/expiration, requirements, attachments, evidence links, signatures/integrity hooks e retention references.

## Não inclui
Implementar storage físico acoplado nem assumir validade jurídica universal de assinatura.

## Entradas
Document/evidence requests, files, metadata e policy requirements.

## Saídas
Document/evidence records e lifecycle events.

## Critério de conclusão
Um processo pode exigir/provar evidência específica sem depender de convenções ad hoc de arquivo.
