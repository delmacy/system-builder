# Escopo — Digital Thread / Lineage Engine

## Inclui
Chronological/causal lineage references, transformation chain, approvals/decisions, artifact ancestry e navigation across lifecycle.

## Não inclui
Duplicar todos os payloads nem substituir dependency graph; lineage enfatiza origem/história.

## Entradas
Evidence/provenance, versioning, artifacts, release/deployment/observation links.

## Saídas
Digital thread navegável e lineage queries/export.

## Critério de conclusão
É possível seguir uma decisão do mundo real até o release/execução e voltar da execução à evidência original.
