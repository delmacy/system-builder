# Escopo — System Design

## Inclui
Entidades, relações, workflows, actions, views, roles, permissions, policies, integrations, jobs/events e requisitos de ambiente/deploy.

## Não inclui
Resolver versões concretas de packages, compilar ou executar o sistema.

## Entradas
SystemAnalysis e contratos dos catalogs/capabilities.

## Saídas
SystemDefinition declarativa, validável e rastreável.

## Critério de conclusão
A definição descreve integralmente o sistema lógico sem depender de internals de módulos produtores.
