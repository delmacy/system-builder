# Escopo — Dependency & Impact Graph

## Inclui
Nodes/edges para process/rule/entity/capability/component/test/release/deployment, graph updates, impact traversal, confidence e affected-set queries.

## Não inclui
Presumir causalidade onde só existe referência nem substituir Digital Thread histórico.

## Entradas
Artifacts e traceability/dependency metadata da pipeline.

## Saídas
Dependency graph, impact reports e missing-link findings.

## Critério de conclusão
Uma mudança proposta pode gerar conjunto justificável de artefatos/testes/releases potencialmente afetados.
