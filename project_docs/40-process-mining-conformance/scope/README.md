# Escopo — Process Mining / Conformance Engine

## Inclui
Event-log preparation, case/activity/timestamp mapping, discovery, variants, conformance checking, deviations, bottleneck statistics e quality/confidence.

## Não inclui
Tratar log incompleto como realidade total ou mudar Recipe automaticamente.

## Entradas
Business event logs, ProcessMirror/Recipe models e semantic mappings.

## Saídas
Discovered models/variants, conformance findings e evidence for improvement.

## Critério de conclusão
Cada finding informa cobertura/qualidade dos dados e pode ser rastreado aos eventos que o sustentam.
