# Escopo — System Builder Self-Hosting

## Inclui
Dogfooding de Mirror/Recipe/Analysis/Definition/Catalog/Observe/Support em partes do próprio produto, comparison against manual process e maturity gates.

## Não inclui
Exigir que o Builder compile integralmente a si mesmo antes da fábrica estar madura.

## Entradas
Processos reais de desenvolvimento/operação do SB e capabilities maduras.

## Saídas
Self-hosted slices, evidence de gaps e feedback arquitetural.

## Critério de conclusão
Partes relevantes do lifecycle do SB usam seus próprios contracts sem criar circular dependency que comprometa bootstrap/autonomia.
