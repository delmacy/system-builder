# Escopo — Process Economics

## Inclui
Volume, lead/cycle time, queue, cost drivers, resource consumption, capacity/utilization, rework, SLA, risk e value dimensions quando disponíveis.

## Não inclui
Inventar ROI onde os dados não permitem nem substituir contabilidade oficial.

## Entradas
Recipe, runtime events, resource/cost data e benchmarks autorizados.

## Saídas
ProcessEconomicProfile, baselines e before/after measures.

## Critério de conclusão
A plataforma consegue explicar quais premissas/dados sustentam uma medida econômica e sua incerteza.
