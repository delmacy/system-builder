# Escopo — Observe

## Inclui
Telemetria técnica e de negócio, ingestão de eventos/métricas, correlação com release/deployment, indicadores e findings.

## Não inclui
Ser dependência necessária do runtime nem alterar processos automaticamente.

## Entradas
Logs, metrics, traces, business events e definições de indicadores.

## Saídas
Observations, séries operacionais, alertas/findings e evidência para evolução.

## Critério de conclusão
Com Observe indisponível o runtime continua operando; quando ativo, eventos podem ser ligados ao contexto correto.
