# Definition of Ready / Done

## Work Package READY
Scope/boundaries; parent WBS; requirements/source; predecessors; interfaces/contracts; acceptance; evidence; risks; downstream consumer; decomposition suficiente; sem decisão crítica delegada ao implementer.

## Task READY
Parent WP; mudança pequena/coesa; allowed paths; forbidden changes; exact inputs/outputs; predecessor satisfied; tests/evidence; rollback note se necessário.

## Task DONE
Implementation + tests pass + evidence + docs/contracts updated + review accepted + no hidden scope expansion.

## Sprint DONE
Increment integrated in shared branch/main according to policy; acceptance demonstrable; unresolved defects classified; risk/issue/lesson updates made.

## Milestone DONE
Outcome ponta a ponta demonstrado; required WP accepted; quality/risk review; release/evidence where applicable; next milestone prerequisites explicit.
