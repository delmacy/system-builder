# Escopo — Data / Reporting / Indicators

## Inclui
Operational queries, exports, report definitions, indicator definitions, aggregation/time windows, dimensions, quality metadata e dashboards.

## Não inclui
Inventar KPIs sem pergunta operacional nem substituir data governance/analytics externos quando melhores.

## Entradas
Runtime/business data, Recipe indicator definitions e authorization context.

## Saídas
Reports, indicators, datasets/exports e visualization feeds.

## Critério de conclusão
Cada KPI relevante possui definição, fonte, fórmula, período e rastreabilidade.
