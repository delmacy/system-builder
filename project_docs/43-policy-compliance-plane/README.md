# 43 — Policy, Standards & Compliance Plane

**Objetivo:** representar fontes normativas, políticas corporativas/contratuais e controles de conformidade como conhecimento versionado e aplicável por contexto, permitindo que requisitos influenciem design, runtime validation e evidence sem espalhar regras hardcoded por cada módulo.

A capability também é a base para **Standards & Regulatory Knowledge** e **Rule-Driven Design**: normas, regulamentos, contratos, frameworks e políticas podem originar RulePacks aplicáveis sobre BusinessRecipe/SystemDefinition/templates sem que a fonte normativa, a interpretação, a regra executável e a evidência sejam confundidas.

Princípio estrutural:

`Source != Interpretation != Applicability != Requirement != Control != RulePack != Template/Design != Enforcement != Evidence != Conformance Claim`

A aplicação deve permanecer jurisdicional, temporal, organizacional e setorialmente qualificada. Nenhuma norma/regulação é presumida aplicável apenas porque existe no catálogo.
