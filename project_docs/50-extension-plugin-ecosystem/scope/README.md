# Escopo — Extension / Plugin Ecosystem

## Inclui
SDK/manifests, capability/connectors/UI extension points, permissions, compatibility, signing/certification, sandbox/isolation e catalog distribution.

## Não inclui
Marketplace obrigatório no MVP nem execução de código de terceiros sem trust policy.

## Entradas
Plugin package/manifest, contracts, permissions e compatibility metadata.

## Saídas
Validated extensions, registry entries e install/upgrade/remove records.

## Critério de conclusão
Uma extensão declara claramente capabilities, permissions, dependencies e compatibility antes de ser carregada.
