# Escopo — Optimization Engine

## Inclui
Objectives, constraints, decision variables, solver adapters, feasible solutions, trade-offs, sensitivity e recommendation evidence.

## Não inclui
Executar recomendação automaticamente por padrão nem otimizar métrica isolada ignorando guardrails.

## Entradas
Process/capacity/economic models, constraints e objectives.

## Saídas
OptimizationResult com feasible alternatives, scores e assumptions.

## Critério de conclusão
Toda recomendação mostra objetivo, constraints, modelo/solver e trade-offs usados.
