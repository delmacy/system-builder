# Escopo — Evidence & Provenance

## Inclui
Identidade de evidência, source references, autoria, timestamps, confidence/classification, input-artifact references, transformation provenance e integrity metadata.

## Não inclui
Substituir Audit Trail de ações runtime nem armazenar obrigatoriamente payload sensível no envelope.

## Entradas
Fontes, artefatos e transformações da pipeline.

## Saídas
Metadata e links de proveniência preserváveis entre contratos.

## Critério de conclusão
É possível responder de onde veio um conhecimento/artefato, quem/que processo o produziu e quais inputs foram utilizados.
