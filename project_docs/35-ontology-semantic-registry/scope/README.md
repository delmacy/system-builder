# Escopo — Ontology & Semantic Registry

## Inclui
Concept identity, definitions, aliases, relations, versions, domain specialization, semantic equivalence/conflict e registry queries.

## Não inclui
Criar DSL empresarial agora nem forçar todos os mercados a um vocabulário inadequado.

## Entradas
Conceitos recorrentes descobertos em Recipes/processes/capabilities.

## Saídas
Semantic concepts versionados e mappings/aliases aprovados.

## Critério de conclusão
Conceitos iguais deixam de proliferar com nomes incompatíveis, sem apagar especializações legítimas.
