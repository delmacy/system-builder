# Escopo — Catalog

## Inclui
Business Catalog (fragments, modules, patterns, templates) e Software Catalog (capabilities, components, connectors, runtime packages), metadados, versões e consulta.

## Não inclui
Fundir conceitos de negócio e software nem resolver uma montagem específica.

## Entradas
Assets aprovados e contratos de registro.

## Saídas
Entradas catalogadas e interfaces de descoberta/resolução.

## Critério de conclusão
Um consumidor consegue localizar e avaliar assets por contrato sem conhecer armazenamento ou implementação interna.
