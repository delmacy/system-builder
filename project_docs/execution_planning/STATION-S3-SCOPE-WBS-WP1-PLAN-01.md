## WP1 — C01 Admission & Schema Contracts

### Starting state

Synthesis and C01 bounding exist. TASK-615 is preparatory material created before this WP baseline and must be reconciled/rematerialized against the exact branch HEAD before code mutation. Required C01 proofs remain UNPROVEN.

### Milestone / required end-state

WP1 reaches its milestone only when Station has a domain-neutral, deterministic, fail-closed admission/schema boundary with executable evidence for:
- valid slot/schema admission;
- invalid tuple rejection;
- malformed/unsupported variant rejection;
- zero canonical mutation on rejection;
- placement/span independent from identity/presentation;
- semantic action not encoded as a visual variant;
- schema-driven Inspector field resolution;
- inherited proofs explicitly named with unchanged preconditions.

Completion of tasks or a green generic test suite alone does not satisfy the milestone.

### Shared foundation vs specialization boundary

WP1 may establish shared Station grammar/schema/admission contracts and a bounded schema-driven Inspector adapter. It must not encode provider-, Tool-, Application-, or Studio-specific semantics. Specializations consume the shared contract through declared schemas/capabilities/adapters; they do not modify shared grammar authority implicitly.

Allowed dependency direction:
`specialization -> shared Station editor foundation -> Station projection/adapter -> owner/Core contract`.

Forbidden directions include Core depending on Studio-specific presentation, shared foundation depending on a domain specialization, projection becoming canonical authority, or AppManifest mutating ComponentRegistry semantics.
